# RPi0-PiholeConfig
Pi0 Pihole boot config files

the zip is the same as the release. it contains all of the extra files with the exception of the stats.py which is the same as the old one released from Adafruit prior to August 2025 (before the major update putting everything into a container (PiHole)). The Archive for IP is making a static from a dynamic one without making the board static. The main reason you'd want to do this is if you image a Pi0 from an active build and it has a static IP and the network changes (any change...) than it causes a IP error and brakes the build.  This way, doesn't care what the router issues for IP and the user has the power to create a static clone.  The clone routes to dynamic one but the router doesn't issue the cloned address; better make sure it's right before you assign and run the build! I did not write any documentation for this, however if you review all of the files inside the archive, it should be evident what happens.
